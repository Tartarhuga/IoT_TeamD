Overview

This section presents my contribution to the M.A.B.I.T.E project through the implementation of a Simon Says memory game on an ESP32-based system.

(Memory Training): Challenges the player’s short-term memory by requiring the reproduction of increasingly complex LED and sound sequences.

(Interactive Feedback): Combines visual cues (LEDs), audio signals (buzzer), and user input (buttons) to reinforce cognitive engagement and learning.

(Progressive Difficulty): Automatically increases complexity as the player succeeds, ensuring a continuous and adaptive cognitive challenge.

Method

This section describes the methodology used to design and implement the Simon Says memory game within the M.A.B.I.T.E project.

Hardware Integration: The game is implemented on an ESP32 microcontroller and uses four LEDs, four corresponding push buttons, a buzzer, and an OLED display. Each LED-button pair represents a unique input channel, allowing intuitive user interaction.

Game Architecture: The software follows a state-based architecture. A sequence of random values is generated and stored in memory. At each new round, one additional element is appended to the sequence, increasing the difficulty progressively.

Interaction and Feedback: The system provides immediate multimodal feedback. Visual feedback is delivered through LEDs, while audio feedback is produced by the buzzer. Player inputs are validated step by step to ensure accurate sequence reproduction.

Performance Evaluation: The player’s performance is measured by the maximum sequence length successfully reproduced. This value is used as the final score and compared to the best score recorded during the session.

Demo

This demonstration presents the complete functionality of the M.A.B.I.T.E cognitive assessment system. The video showcases all implemented mini-games and their interaction within the unified menu-driven interface.
The demonstration includes:
  • Simon Says: memory-based sequence reproduction using LEDs and buttons.
  • 10-Second Timer Challenge: evaluation of time perception accuracy.
  • Reflex Challenge: measurement of reaction speed through LED stimuli.
This demonstration highlights the coherence between the different games, the consistency of user interaction, and the use of multimodal feedback to create a complete and engaging cognitive testing environment.
